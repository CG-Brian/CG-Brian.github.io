Selected Work

Things I’ve designed and built end to end, mostly small and sharp, a few still running in production.

  1. 01

    Tessellate

    An embeddable vector index in Rust. Product quantization and a SIMD distance kernel keep a 10M-vector corpus in under 2 GB of memory.

    Rust · ANN · SIMD

    2025

  2. 02

    Murmur

    On-device speech-to-intent for low-power hardware. A distilled 18M-parameter model with a 4-bit runtime that answers in 40 ms.

    PyTorch · C++ · Quantization

    2024

  3. 03

    Ledger

    A local-first sync engine built on delta-state CRDTs. Offline edits merge deterministically, with no central server needed to resolve conflicts.

    TypeScript · CRDTs · WebRTC

    2024

  4. 04

    Quill

    A small typesetting language that compiles to PDF. It has a hand-written parser, incremental re-layout, and a Knuth–Plass line breaker.

    OCaml · Compilers · Typography

    2023

  5. 05

    Atlas

    A streaming geospatial tile server that renders vector tiles from live sensor feeds for a city transit authority.

    Go · PostGIS · Kafka

    2022

About

I’m a software engineer who likes problems that sit between disciplines, where a result from numerical analysis decides whether a distributed system is fast enough, or a compiler technique makes a model small enough to ship.

I studied mathematics before moving into engineering, and I still work the same way: understand the foundations, build the smallest thing that tests an idea, then write it down carefully enough that someone else can disagree with it.

Outside of work I set type, run long distances slowly, and keep a reading list that is longer than it should be.
